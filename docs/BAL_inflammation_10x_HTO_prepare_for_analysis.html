Set-up

This markdown prepares the BAL inflammation dataset for analysis. The dataset was downloaded from the Zenodod. We selected batch 9 for this analysis as this batch contained 8 samples, each from different donors. Batch 3 was sequenced in two captures (each of which contains all samples), which are referred to as C133_batch3_1 and C133_batch3_. Here, we only focus on C133_batch3_1.

The files downloaded are

  • raw feature_bc_matrix.h5 file (C133_batch3_1)

  • processed SCE object for all of batch 3 (C133_batch3_1+C133_batch3_2) - the code for how this object was produced can be found here. Note that the metadata for this object includes HTO and vireo results for doublet/singlet calls. We will need to filter out barcodes from the second capture.

We will export a cellranger like output structure that contains both singlets and doublets.

Prepare cellranger output

Make cellranger output files for barcodes that were detected as non-empty by the original authors (based on their SCE object).

Make SCE object and add QC metrics

#change rownames from metadata as they follow the old nomenclature that is no longer relevant
rownames(meta_batch_3_1) <- meta_batch_3_1$Barcode

export_sce <- SingleCellExperiment(assays = c("counts" = counts_raw[, meta_batch_3_1$Barcode]), 
                                   colData =meta_batch_3_1 %>% DataFrame())
  
#add QC metrics
is.mito <- grepl(pattern = "^MT", rownames(export_sce))
is.ribo <- grepl(pattern = "^RP[SL]", rownames(export_sce))
export_sce <- addPerCellQCMetrics(export_sce, subsets = list(mito = is.mito, ribo=is.ribo))

#clean up
new_meta <- export_sce@colData %>% as.data.frame() %>%
  dplyr::rename(.,nfeatures_raw = detected, ncount_raw = sum, subsets_mito_percent_raw = subsets_mito_percent, subsets_ribo_percent_raw=subsets_ribo_percent) %>%
  select(., -c("subsets_mito_sum", "subsets_mito_detected", "total", "subsets_ribo_sum", "subsets_ribo_detected", starts_with("altexps")))

export_sce@colData <- new_meta %>% DataFrame()
