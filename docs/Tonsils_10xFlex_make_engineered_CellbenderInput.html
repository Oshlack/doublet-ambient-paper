Set-up

This markdown will generate CellBender appropriate input files. CellBender traditionally takes the raw h5 file produced by cellranger as input and performs both cell-calling as well as ambient removal. For the engineered datasets, we will need to generate equivalent files containing the cells (generated here) as well as empty cells (generated here).

CellBender performs a lot better when provided with the input parameters expected-cells and total-droplets-included. We can estimate both of these input parameters from the resulting knee plot. In our case, we actually know the number of expected cells is going to be 12,000

Combine empty cells + engineered to generate h5 file output

Write a function to do this.

run_combine_export <- function(cells, 
                               empties,
                               name){
  #make sure genes match
  gene_universe <- intersect(rownames(cells), rownames(empties))
  cells <- cells[gene_universe,]
  empties <- empties[ gene_universe,]
  #check order 
  stopifnot(all(rownames(cells) == rownames(empties)))
  
  #combine
  combined <- cbind(counts(cells),counts(empties))
  
  #export
  filename <- sprintf("%s/%s_cellbenderInput_feature_bc_matrix.h5", unique(dirname(list_datasets_paths)), name)
  write10xCounts(path = filename,
               x = combined,
               type = "HDF5",
               version = "3",
               barcodes = colnames(combined),
               gene.symbol = rownames(combined), 
               overwrite = TRUE)
  print(filename)
  return(combined) #keep file name
}

Make Kneeplots for engineered datasets

For each of the engineered ‘raw’ files, let’s make a kneeplot and highlight potential thresholds for -total-droplet-included. The -total-droplet-included does not have to be exact- every droplet/barcode past that threshold will however be treated as an empty droplet.

Make a function

run_kneeplot <- function(counts, 
                         label_df, 
                         name){
  bcrank <- barcodeRanks(counts) #using DropletUtils function
  bcrank_filtered <- bcrank[!duplicated(bcrank$rank), ]# only show unique points for plotting speed
  
  ggplot(data = bcrank_filtered, aes(x = log10(rank), log10(total))) + geom_point()+
    geom_vline(data= label_df, mapping = aes(xintercept = log10(num), colour = name)) +
    theme_bw() +
    scale_colour_manual(values = unname(Polychrome::alphabet.colors(nrow(label_df))))+
    theme_bw() + theme(legend.title = element_blank(), legend.text = element_text(size=15), 
                       legend.spacing.y = unit(0.5, "cm"), legend.key.spacing.y = unit(0.5, "cm"))+
    guides(colour = guide_legend(override.aes = list(linewidth = 2)))+
    ggtitle(sprintf('Knee plot:\n%s', name))
  
}
#set same test thresholds for all
label_df <- data.frame(name=c("cells_12k", "droplet_45k"),
                       num = c(12000, 45000))

plot_list <- sapply(1:length(list_out), function(IN){
