Set-up

This markdown performs doublet calling using scDblFinder on the whole, decontX corrected Tonsil 10x Flex dataset. This includes:

  • decontX correction - no background provided

  • removal of low quality cells (post-ambient correction)

  • scDblFinder doublet calling, split per sample

  • clustering (using Seurat)

  • export of results as qs2 object, as well as in 10X cellranger output format

QC filtering

Low quality cells will be removed prior to performing doublet detection. Our main goal here is to eliminate cells with a very low library size and/or number of genes detected, as well as cells with unusually high % mitochondrial reads as their presence may interfere with doublet calling. 10X flex does not have any probes for ribosomal genes. We are performing this on ambient RNA corrected data. We define the number of genes expressed as the number of genes that have a count >0.5.

Doublet calling - scDblFinder

Running scDblFinder for doublet detection. We have already removed cells with very low library size and very high mitochondrial content. scDblFinder requires a standard workflow to be run on the SCE. As recommended by the authors, we are applying scDblFinder for each sample separately by using the samples parameter.

#standard workflow
sce_filtered <- logNormCounts(sce_filtered) %>%
  runPCA() %>%
  runUMAP()

#scDblFinder
set.seed(1997)
sce_filtered <- scDblFinder(sce_filtered,
                   clusters = T,
                   dbr.sd = 1, #removing doublet rate assumption 
                   samples = "Sample", 
                   verbose=F)
