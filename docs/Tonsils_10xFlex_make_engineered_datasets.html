Set-up

This markdown generates the engineered dataset using the 10xFlex tonsil dataset. This process has four key steps: Filter, combine, annotate and subset. To avoid confusion, please review the following table for commonly used terminology in this markdown”

Term(s) Description
cell/pseudo-GEM/pseudo_droplet We use these terms interchangeably with barcodes. It describes a unique combination of sample and droplet barcode, which ideally would be one single-cell, and corresponds to a GEM in regular single-cell
droplet/GEM We refer to a droplet/GEM as the combination of all cells that carry the same droplet barcode. These cells were co-captured in GEMs during the sequencing process and are therefore true multiplets that we can re-create
pre-QC GEM occupancy The number of cells that carry the same droplet barcode prior to performing QC filtering. This corresponds to the occupancy of the droplet at sequencing
post-QC GEM occupancy The number of cells that carry the same droplet barcode after performing QC filtering.

1. Filter: get a set of high-confidence singlets

The purpose of these filtering strategies is to ensure that we start off with a collection of high confident single cells. To this end, we

  • remove cells with a library size < 200, < 150 unique genes expressed and %mito content > 7%. Note that these thresholds are purposefully lenient to ensure we still capture the full cell type diversity present in the dataset.

  • remove cells that were not called as ‘cells’ by both DropletUtils::emptyDrops() and cellranger multi. This consensus approach increases the likelihood of barcodes being true cells.

  • only keep cells that were considered singlets by 4 different doublet detection tools (scDblFinder, scrublet, DoubletDetection, scds). This is to maximise the likelihood of remaining singlets to be true singlets, and prevents us from adding more than two cells when creating pseudo-droplets.

  • only keep cells for whose pre and post-QC GEM occupancy is 1 or 2. These correspond will then become singlets (1) and doublets (2) after combining them into pseudo-droplets.

As a final comment, we recognise that some resulting cells may not be perfect single cells but in general they can be considered high confident single cells.

2. Combine: generate pseudo-droplets from singlets

The resulting set of high confidence singlets are then combined based on their droplet barcodes. For doublets, the gene expression is combined for the two cells.

3. Annotate: add detailed information describing pseudo-droplets

Finally, we add in-depth information for each pseudo-droplet. This is particularly unique and useful for the doublets! Metrics include:

  • RNA contribution of each cell to pseudo-droplet content (in fraction + absolute library size)

  • cosine similarity between cells within doublets

4. Subset: reduce dataset size and doublet proportion

The resulting dataset can then be subset to desired dataset size as well as doublet proportion.

2. Combine: generate droplets from singlets

As a next step, we combine the counts for cells originating from the same droplet. To achieve this we’ve written a function to generate droplet based gene expression matrices.

# function written by Geroge Howitt
makeGEMMatrix <- function(sce) {
  counts_matrix <- counts(sce)
  dimnames(counts_matrix)[[2]] <- substring(dimnames(counts_matrix)[[2]], first = 1, last = 17) #first 17 bases are droplet barcodes
  counts_matrix <- as(counts_matrix, "TsparseMatrix")
  nms <- colnames(counts_matrix)
  uniquenms <- unique(nms)
  GEM_counts <- sparseMatrix(i = counts_matrix@i+1,
                             j = match(nms, uniquenms)[counts_matrix@j + 1],
                             x = counts_matrix@x,
                             dimnames = list(rownames(counts_matrix), uniquenms),
                             repr = 'T')
  return(as(GEM_counts, "CsparseMatrix"))
}

Apply function to generate droplet object.

4. Subset: reduce dataset size and doublet proportion

Finally, we will subset the resulting pseudo droplet dataset to a desired dataset size and doublet proportion

Writing a function to subset the object based on input #doublets and #singlets, then exports the resulting matrix. We will run this 5 times with different seeds.

run_subset_droplets <- function(object, 
                                n_doub, 
                                n_singlet,
                                seed){
  set.seed(seed)
  #get random subsets
  cells <- c(sample(object$GEM_barcode[object$doublet_class == "doublet"],  n_doub, replace = F), 
           sample(object$GEM_barcode[object$doublet_class == "singlet"],  n_singlet, replace = F) 
           )
  #subset
  sub <- object[, object$GEM_barcode %in% cells]
  #export
  filename <- sprintf("%s/Tonsils_10xFlex_engineered_%ik_%0.2fp_%is",
                      here("output/data/Tonsils_10xFlex/Engineered/"), 
                      (n_doub+n_singlet)/1000, 
                      n_doub/(n_doub+n_singlet),
                      seed)
  print(basename(filename))

  DropletUtils::write10xCounts(path = filename,
                               x = counts(sub),
                               version = "3")
  #export metadata
  filename_meta <- sprintf("%s/Tonsils_10xFlex_engineered_%ik_%0.2fp_%is/metadata.tsv",
                      here("output/data/Tonsils_10xFlex/Engineered/"), 
                      (n_doub+n_singlet)/1000, 
                      n_doub/(n_doub+n_singlet),
                      seed)
  write_tsv(x=as.data.frame(sub@colData),
            file=filename_meta)

  rm(sub, cells)
  
}
