Set-up

This markdown prepares the Lung Cancer dataset for analysis. The dataset was downloaded from the 10X Genomics website. The files downloaded are

  • the filtered feature_bc_matrix.h5 files per sample

  • CMO config file

  • raw feature_bc_matrix.h5 file (all samples)

  • multiplexing results file

To generate a dataset with ground-truth doublet labels (based on CMO counts), we need to export a cellranger like output strucutre that contains both singlets and doublets. Currently, the doublets are filtered out from the filtered output matrix and hidden in the raw h5 file.

Prepare metadata

Prepare cell metadata

We only have demultiplexing results for cells called by cellranger, so that will be our baseline. In addition, we’re adding all multiplets, though we will give them different names for now depending on what their occupancy is.

cell_info <- CMO_information %>%
  mutate(., doublet_class = case_when(num_features == 1 ~ "singlet", 
                                      num_features == 2 ~ "doublet",
                                      num_features>2 ~ "multiplet")) %>% 
  select(., cell_barcode, doublet_class) %>%
  dplyr::rename(Barcode = cell_barcode) %>%
  left_join(., all_barcodes) %>% 
  mutate(., Sample = ifelse(is.na(Sample), "CMO_multiplet", Sample))

#Make SCE
sce <- SingleCellExperiment(assays = c("counts" = counts_filtered), colData =cell_info)
sce <- sce[rowSums(counts(sce) ) > 0,]

#add QC metrics
is.mito <- grepl(pattern = "^MT", rownames(sce))
is.ribo <- grepl(pattern = "^RP[SL]", rownames(sce))
sce <- addPerCellQCMetrics(sce, subsets = list(mito = is.mito, ribo=is.ribo))

#clean up
new_meta <- sce@colData %>% as.data.frame() %>%
