Set-up

This markdown will generate an empty droplet object that can be used as background for ambient RNA correction tools, such as soupX and decontX.

To avoid confusion, please review the following table for commonly used terminology in this markdown”

Term(s) Description
cell/pseudo-GEM/pseudo_droplet We use these terms interchangeably with barcodes. It describes a unique combination of sample and droplet barcode, which ideally would be one single-cell, and corresponds to a GEM in regular single-cell
droplet/GEM We refer to a droplet/GEM as the combination of all cells that carry the same droplet barcode. These cells were co-captured in GEMs during the sequencing process and are therefore true multiplets that we can re-create
empty cell cells/barcodes which are considered empty by both cellranger multi and DropletUtils::emptyDrops()
empty droplet droplets which do not contain any non-empty cells

In 10xFlex data, the raw count matrix is presented as cell x gene matrices. In regular droplet based approaches, this is equivalent of saying it represents a droplet x gene matrix. All ambient RNA correction tools were designed under the assumption that each column in the matrix is a droplet - however, this assumption is not met in 10x Flex data. There is no general recommendation for whether the background should be provided as empty droplets (so cells combined based on their droplet barcode) or empty cells (matrix as is). The distribution of ambient RNA in 10xFlex is not fully understood.

For the purpose of we therefore clarify in detail how we define the background in detail here as well as in the methods.

  • determine empty cells using both cellranger multi as well as DropletUtils::emptyDrops()

  • only keep “empty cells” that come from droplets where no cells were called

  • Combine resulting “empty cells” into their respective “empty droplets” based on their droplet barcode. The resulting background object will be in droplet x gene format

create empty droplets object

Only keep cells that are considered empty by both cellranger multi as well as DropletUtils::emptyDrops(), then only keep empty cells that come from droplets with no cells in them. Re-combine into empty droplets using George’s function.

# function written by George Howitt
makeGEMMatrix <- function(sce) {
  counts_matrix <- counts(sce)
  dimnames(counts_matrix)[[2]] <- substring(dimnames(counts_matrix)[[2]], first = 1, last = 17) #first 17 bases are droplet barcodes
  counts_matrix <- as(counts_matrix, "TsparseMatrix")
  nms <- colnames(counts_matrix)
  uniquenms <- unique(nms)
  GEM_counts <- sparseMatrix(i = counts_matrix@i+1,
                             j = match(nms, uniquenms)[counts_matrix@j + 1],
                             x = counts_matrix@x,
                             dimnames = list(rownames(counts_matrix), uniquenms),
                             repr = 'T')
  return(as(GEM_counts, "CsparseMatrix"))
}
# make sure to remove genes with no expression across the board as this breaks the function
empty_droplet <- SingleCellExperiment(assays = list(counts=makeGEMMatrix(raw_sce_subset[rowSums(counts(raw_sce_subset)) > 0,])))
